🧠 Data Structures Used

Hash Table: JavaScript Map is used to store books using Book ID as the key. It provides fast lookup and duplicate ID checking.

Binary Search Tree: Books are inserted into a Binary Search Tree according to their Book ID. This demonstrates efficient searching and ordered data storage.

Firebase Firestore: Cloud database used to permanently store, retrieve, update and delete book information.
