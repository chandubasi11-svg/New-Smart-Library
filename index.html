💡 Data Structures Used

Hash Table: Used for fast book searching using Book ID. Average search time is O(1).

Binary Search Tree: Used to organize books based on their Book ID. Searching and insertion have an average time complexity of O(log n).

Firebase Firestore: Used as the cloud database to store book information permanently.

Update Function: Allows the administrator to edit book title, author and category.
