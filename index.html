💡 Data Structures Used

Hash Table: Used for fast book searching using Book ID. Average search time is O(1).

Binary Search Tree: Used to organize books based on Book ID. Searching and insertion have average time complexity O(log n).

Firebase Firestore: Used as the cloud database to permanently store book information.

Update Function: Allows the librarian to edit book information and update it in Firebase.
